# Стендап: что сделано вчера

Собери отчёт о работе за **вчерашний день** для стендапа. Отчёт — короткий, двумя короткими секциями («Что сделано», «Блокеры/в работе»), без списков, хэшей и перечисления файлов: только общая суть.

## Как собрать данные

1. Определи вчерашнюю дату динамически (`date -d "yesterday"`), не хардкодь.
2. Собери commit'ы автора `Alexander Medentsov` за вчера по всем веткам:

```bash
git log --author="Alexander Medentsov" \
        --since="<вчера> 00:00" --until="<сегодня> 00:00" \
        --no-merges --all --oneline
```

3. Если по сообщению коммита суть непонятна — уточни по `git show --stat <hash>`, но **в отчёте ссылки на хэши/файлы не выводи**.
4. Сгруппируй изменения по фичам/областям (api, web, shared, docs, инфраструктура).

## Формат отчёта

Выведи на русском две короткие секции с заголовками:

- **Что сделано** — перечисли суть сделанных задач и их область, без хэшей, веток и файлов.
- **Блокеры/в работе** — кратко, если есть незавершённые вещи; если вчера коммитов не было — честно так и написать.

Не придумывай ничего, чего нет в git-истории. Не выводи даты в ответе как хэши/списки — только смысл.
