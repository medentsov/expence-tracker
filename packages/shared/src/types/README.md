# types

Общие типы и DTO трекера расходов, используемые фронтендом (`@tracker/web`) и бэкендом (`@tracker/api`):

- `currency.ts` — коды валют и их отображение
- `category.ts` — категория расходов
- `expense.ts` — единичный расход
- `user.ts` — пользователь, ответ авторизации и входные данные login/register

В будущих итерациях здесь появятся типы для отчётов/статистики.
